# X-Theta Phase 2: Predictive Relational Geometry

This document outlines the Phase 2 research program for the X-Theta framework.

## 1. Overview

X-Theta Phase 2 moves from simple phenomenological fitting of Bell-test data to a predictive relational geometry framework. The core goal is to enable falsifiable predictions of entanglement anisotropy induced by curved spacetime.

## 2. Research Pillars

### Pillar A: Clean Validation Discipline
- Robust adapters for open Bell-test data (e.g., Hensen et al. 2015).
- Clear distinction between phenomenological fits and physical predictions.
- Strict audit trails for data processing.

### Pillar B: Predictive X-Theta Theory
- Derivation of the relational generator $G_{rel}$ from symmetry or action principles.
- Mathematical characterization of the correlation tensor anisotropy $T(\Phi)$.
- Invariant analysis ($R_\Theta$).

### Pillar C: Future Experiment Design
- Definition of metadata requirements for physical X-Theta tests.
- Design of satellite-based Bell experiments with high curvature sensitivity.
- Implementation of falsification rules.

## 3. Claim Levels

We adopt a four-level classification for all research claims:

1. **Theorem**: Proven mathematically (e.g., the structure of $T(\Phi)$).
2. **Simulation**: Verified numerically (e.g., synthetic phase recovery).
3. **Phenomenological Fit**: Describes data without proving cause (e.g., Hensen $\Phi_{eff}$).
4. **Physical Prediction**: Predicted before measurement from geometry (Future experiments).

## 4. Falsification Rules

A theory is only as strong as its falsification criteria. X-Theta is constrained or falsified if:
- Predicted phase is non-zero but measured anisotropy is zero.
- Observed anisotropy does not scale with predicted gravitational geometry.
- The same signal appears in control experiments without geometry changes.
